# Pinocchio 1.0.0

Мод для **RimWorld 1.6 и Hardcore SK**, автор — Fyren_Selvin.
Пиноккио — люди, чьи конечности и органы заменены примитивными протезами.

## Требования

- RimWorld 1.6 с DLC Biotech.
- Установленная и настроенная сборка Hardcore SK, включая Core SK и её зависимости.
- Harmony. Pinocchio должен загружаться после Harmony, Biotech и Core SK.

Релиз проверен автономными тестами на установленной RimWorld 1.6.4871 и HSK
1.6.926.30. Он не предназначен для чистой игры без HSK. Поддержка RimWorld 1.5
для этого релиза не заявляется. Odyssey не обязателен; его ветка сценариев
не проходила игровой проверки.

## Установка и обновление

1. Закройте RimWorld. При обновлении сохраните резервную копию своих сохранений.
2. Распакуйте папку `Pinocchio` из архива в `RimWorld/Mods`.
   Файл описания должен оказаться по пути `RimWorld/Mods/Pinocchio/About/About.xml`.
3. Если Pinocchio уже установлен, замените его папку целиком. Предварительно
   сохраните свои изменения исходников вне каталога Mods, если они есть.
   Не оставляйте вторую копию мода в Mods.
4. Включите Pinocchio в списке модов после зависимостей и перезапустите игру.

Идентификатор мода остаётся `fyrenselvin.pinocchio`; существующие определения
и имена настроек сохранены. Колонисты в уже созданном сохранении автоматически
не переделываются. Полный цикл загрузки и сохранения с релизным архивом отдельно
не проверялся.

## Сценарии

- **Pinocchio** — трое взрослых Пиноккио после крушения, выбор из восьми кандидатов.
- **Пиноккио: потерянное племя** — пятеро Пиноккио, взрослые или дети, выбор
  из восьми кандидатов. Условия племенного старта HSK, 300 пеммикана вместо 220
  и бронзовый нож, совместимый с используемыми определениями HSK.

Повторная генерация через «Случайно» сохраняет принадлежность к Пиноккио,
в том числе при работе Humanoid Alien Races. Племенной сценарий сохраняет
племенной тип персонажей.

## Настройки

Откройте настройки модов → Pinocchio. Интерфейс настроек на русском языке.
Можно отдельно включать замену рук, ног, внутренних органов, частей головы
и таза. Всего в каталоге 20 вариантов протезов.

Все группы замен включены по умолчанию. Вероятность замены каждого внутреннего
органа по умолчанию 100%; ползунок меняет только внутренние органы.
Для частей головы действуют отдельные случайные проверки. Последний зрячий
глаз защищён, существующие протезы и вложенные замены не перезаписываются.

Принудительное превращение новых колонистов в Пиноккио **выключено по умолчанию**.
При включении оно применяется к присоединяющимся человекоподобным пешкам.

## Проверки и границы совместимости

При подготовке архива выполняются шесть наборов проверок: планировщик протезов,
состав DLL, запросы стартовых персонажей, совместимость с HAR, племенной сценарий
и ссылки на определения HSK. Дополнительно проверяются XML и содержимое ZIP.
Эти проверки не заменяют игровой прогон всей сборки модов.

Pinocchio не исправляет ошибки генерации товаров торговцев, состояний Core SK,
WikiRim или других сторонних модов. При сообщении об ошибке приложите журнал
из игрового сеанса после установки текущей версии и опишите действие перед ошибкой.

## Для разработчиков

Исходники: https://github.com/FyrenSelvin/Pinocchio-for-Rimworld-HSK

В рабочем репозитории, расположенном в `RimWorld/Mods/Pinocchio`, выполните
`pwsh -NoProfile -File Source/Build-Release.ps1`.
Нужны .NET SDK, PowerShell 7, библиотеки установленной игры/Harmony/HAR
и актуальный экспорт HSK `Mods/Unified.xml` для автономных проверок.
Скрипт создаёт архив, SHA256 и отчёт в `Releases`.

## English

Pinocchio adds a human xenotype with primitive prostheses and two starting
scenarios to RimWorld 1.6 / Hardcore SK. Requires Biotech, Harmony and the HSK
modpack. Extract the `Pinocchio` folder into `RimWorld/Mods`, enable it after
its dependencies, then restart the game. Replace the old mod folder when upgrading.
Do not keep duplicate installations. Settings are in Russian. Existing pawns
are not automatically converted on save load. RimWorld 1.5 is not supported by
this release. Automated verification does not constitute a full in-game test.
